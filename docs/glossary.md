# Sokra 用語集

開発中に繰り返し出てくる言葉を揃えるための用語集。
UIラベルそのものではなく、設計・実装・議論で使う基準語を定義する。

## 会話UI

### AIタイピング表示

AIが返答前に表示する `...` のアニメーション。
英語では `typing indicator` が近い。

- 推奨呼称: AIタイピング表示
- 英語メモ: typing indicator
- 備考: 「AIが入力している感じを出す表示」と説明してもよい

### 自動フォロー

ユーザーが無言のまま一定時間経過したとき、AI側から軽く投げる一言。

- 例: 「一言だけでも大丈夫です。」
- 備考: 追い立てにならないよう、間隔と回数を制御する

### ボタンフェーズ

会話冒頭の選択式フェーズ。自由入力の前に基本コンテキストを集める。

- 例: 参加形式、参加タイミング、温度感

### 自由会話フェーズ

ボタンフェーズ後の通常会話パート。
隠れたチェックリストを内部で持ちながら、自然会話で回収する。

## 会話設計

### 通過地点

会話の中で自然に回収したい内部トピック。
UIには出さないが、進行管理には使う。

- 例: 参加背景、温度感、印象点、違和感・難しさ、実務との接点

### 雑談フック

会話を自然に始めたり、少し横に広げたりするための軽い話題の取っかかり。
分析目的ではなく、摩擦を下げるために使う。

### 知覚のふり

AIが知覚を持っているように見える言い回しを使うこと。
話題として扱うのはよいが、観測事実として語ってはいけない。

- 避ける例: 「もう外は暗いですね」
- 許容例: 「そう言うことはできるけど、実際に外を見ているわけではない」

## 記録・運用

### 用語方針

`ログ` という単語は単独では使わず、なるべく用途を明示する。

- 会話を保存したもの: 会話記録
- 開発や障害調査のためのもの: 開発ログ / アプリケーションログ / デバッグログ

### 会話記録

1回のインタビュー単位で保存された会話。
参加者とAIのやり取りそのものを記録したもの。
現在は `data/sessions/*.jsonl` に保存する。

### 部分記録

途中離脱を含む未完了セッションの会話記録。
失敗扱いせず、価値のある記録として扱う。

### 開発ログ

動作確認、障害解析、デバッグのために出力する内部向けログ。
混同しやすいため、実装する場合は会話記録とは明確に分けて扱う。

- 例: サーバー起動ログ、APIエラーログ、デバッグ出力

### 使用量表示

Gemini API のトークン使用量と概算コストを表示するデバッグ欄。
開発用の観測情報であり、参加者向けの主要UIではない。
